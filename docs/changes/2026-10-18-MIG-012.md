# MIG-012 — Nativer GUI-Prototyp und vorläufige Toolkit-Entscheidung

- Datum: 2026-10-18 (Europe/Berlin). Eigentümer und Integrator: Claude.
- Branch `claude/mig-012-gui-prototype`; Taskbasis siehe [Taskdatei](../tasks/MIG-012.md); Code-Commits `5b50da1`, `914e022`, `ae5d466`.
- Warum: P1 verlangt einen sichtbaren, nativen GUI-Prototyp mit nachgewiesener Accessibility, bevor das Toolkit angenommen wird (ADR-0002).

## Was

- Neues Crate `crates/armasync-gui` (egui/eframe 0.37 mit AccessKit, `egui_extras`; Test: `egui_kittest`), Binary `armasync-gui`. Eigene `rust-version = "1.95"`; der übrige Workspace bleibt bei MSRV 1.85.
- `model.rs`: anzeigefreies View-Model (Liste mit 10.000 synthetischen Repositories, Filter, Sortierung, Auswahl und Tastaturbewegung, Dialog mit Feldvalidierung, Job auf Worker-Thread über `armasync_application::sync` mit Fortschritt, Abbruch, Fehlerzusammenfassung; Kennwort wird nie ausgegeben).
- `ui.rs`: Zeichnen (Toolbar, Filter, Sortierung, virtualisierte Tabelle, Fortschrittsleiste, Fehlerliste, modaler Dialog), Theme und Skalierung, kontrastgeprüfte Farben (`themed_visuals`), AccessKit-Auszeichnung (Listenzeilen als `ListBoxOption` mit Auswahl und Position, benannter `Dialog`).
- `contrast.rs`: WCAG-Kontrastberechnung.
- Prüfprotokoll [GUI_PROTOTYPE_EVIDENCE](../migration/GUI_PROTOTYPE_EVIDENCE.md) mit Screenshots und Abhängigkeitsliste; [ADR-0002](../adr/0002-gui-toolkit.md) um das Prototypergebnis ergänzt (Status „vorläufig gewählt“); RUST_TOOLCHAIN.md angepasst.
- Die Daten sind **simuliert** (In-Memory); es gibt keinen echten Transport oder Dateizugriff, das Fenster weist darauf hin.

## Prüfungen (tatsächlich ausgeführt)

Windows 11 (10.0.26200), Rust 1.99.1:
- `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, `cargo test --workspace --locked`: 81 Tests bestanden (GUI-Crate 29: 12 View-Model/Kontrast, 17 UI und Accessibility).
- MSRV: `cargo +1.85.0 test --workspace --exclude armasync-gui --locked` bestanden. `cargo tree -p armasync-cli`: keine GUI-/Windowing-Crates.
- Live-Start der `armasync-gui.exe` und Abfrage über UI Automation: Fenster, Buttons, ComboBoxen, Edit, 10.000-Zeilen-Liste als ListItem mit SelectionItemPattern, Dialog als Window mit Kennwortfeld (`IsPassword`), Fokusrückgabe nach Escape, ProgressBar (RangeValue) mit Fortschritt 2/6/9/11 von 11, Abbruch, Fehlerzustand. Screenshots im Evidenzordner.
- Durchschnittliche Framezeit mit 10.000 Zeilen headless ca. 3 ms (Debug).

WSL2 Ubuntu (Linux 6.18, Rust 1.99.1, LF-Clone `claude/mig-012-gui-prototype` @ `579ee66`, nach den letzten Code-Änderungen erneut ausgeführt): `cargo build -p armasync-gui` bestanden (ca. 47 s), `cargo fmt --check`, `clippy -D warnings` und `cargo test --workspace --locked` (81 Tests) bestanden. Der GUI-Start unter WSLg scheitert (siehe Offene Punkte).

Beim Test gefundene und behobene Probleme (Details im Protokoll): fehlende Symbolglyphen der egui-Standardschrift (Absturz), Auswahlzustand der Listenzeilen nur als „gedrückter Schalter“, dunkles Theme mit zu geringem Kontrast für schwachen Text (2,27:1) und Widget-Umrisse (1,22:1), unbenannter Dialog, abgeschnittene Tabellenspalte, ein zu schwacher Selbsttest.

## Offene Punkte (kein P1-GUI-Gate)

- **NVDA** nicht ausgeführt (nicht installiert; keine Installation ohne Freigabe). **Orca** nicht ausgeführt (nicht installiert); der Prototyp **startet unter WSLg nicht** (Wayland: `Connection reset by peer`, X11: `libxkbcommon-x11.so` fehlt). Manuelle Prüfschritte stehen im Protokoll. Das P1-Gate für GUI/Accessibility gilt deshalb als **nicht erfüllt**; ADR-0002 bleibt „vorläufig gewählt“.
- Helles Theme/200 % nur berechnet bzw. im Harness; Auswahlfläche im hellen Theme nur 1,56:1 (Ausnahme dokumentiert); Tabellensemantik, Fortschrittsansage-Drosselung, Hochkontrastmodus, macOS nicht geprüft; Alternativen (Slint, Iced, Tauri) nicht prototypisiert.
- Lizenzen der GUI-Abhängigkeiten (ca. 400 Pakete, u. a. egui-Standardschriften unter OFL-1.1/Ubuntu-font-1.0) sind nur nach Metadaten inventarisiert; Notices fehlen (RQ-06 offen). Keine Altassets übernommen (RQ-04). Keine Rechtefreigabe.
