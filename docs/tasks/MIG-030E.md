- Ziel: Komprimierte Blätter (`compressed = true`) werden als Dateien mit dem Zielpfad `<name>` synchronisiert: der Server liefert `<name>.zip` mit der Größe `compressedSize`; das Archiv wird vollständig in eine Spool-Datei geladen, genau ein Dateieintrag wird begrenzt entpackt, Größe und SHA-1 des Ergebnisses gegen das Manifest geprüft und erst dann atomar committet.
